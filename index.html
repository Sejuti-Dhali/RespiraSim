Method and scope

Experiment 07, Problem 1 uses a sinusoidal ventilator pressure, Q(s)/P(s) = (s + 420)/(s² + 620s + 4000), and integration of flow to obtain volume. The simulator uses zero initial states and a 15-second window. The optional RC model is an independent educational extension: dV/dt = (P − V/C)/R. It is not the report's Problem 2 differential-equation implementation. Values are in model units; no clinical calibration is asserted.

Source: Simu_lab_report_merged.pdf, PDF pages 154, 159, 163 and 165. The report's Problem 2 is included for reference, not claimed as reproduced. All generated curves are numerical predictions, not measured patient data.
